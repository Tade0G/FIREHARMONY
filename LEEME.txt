FIREHARMONY — CONECTOR NASA FIRMS

1) Solicitá una MAP_KEY gratuita: https://firms.modaps.eosdis.nasa.gov/api/map_key/
2) Instalá Python 3.10+ y abrí una terminal en la carpeta del proyecto.
3) Instalá dependencias: pip install -r requirements.txt
4) Windows PowerShell: $env:FIRMS_MAP_KEY="TU_CLAVE"
   Windows CMD: set FIRMS_MAP_KEY=TU_CLAVE
   macOS/Linux: export FIRMS_MAP_KEY="TU_CLAVE"
5) Ejecutá: python app.py
6) Abrí http://127.0.0.1:5000
7) Elegí área, fecha, 1-5 días y sensores; presioná Consultar datos reales NASA.

La clave queda como variable de entorno del servidor, no dentro del HTML.
La app consulta MODIS_NRT, VIIRS_SNPP_NRT, VIIRS_NOAA20_NRT y VIIRS_NOAA21_NRT.
El área se aproxima mediante un rectángulo envolvente. Las detecciones no son incendios únicos.
La API de área consulta ventanas de hasta 5 días. Para historia extensa, usar archivos históricos FIRMS y cargar CSV.

Documentación: https://firms.modaps.eosdis.nasa.gov/api/area/

CARTELERA DEL CLIMA — METEOMATICS

    Configurá en el archivo local .env las credenciales de Meteomatics:
   METEOMATICS_USER=tu_usuario
   METEOMATICS_PASSWORD=tu_contraseña
